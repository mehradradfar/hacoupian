# Hacoupian — homepage redesign concept

An animated, scroll-driven prototype of a redesigned Hacoupian homepage, made by [@mehrad.ux](https://instagram.com/mehrad.ux) for the "redesigning Iran's best-known luxury brands" series.

This is a design concept. It is not Hacoupian's official website, and the photos are AI-generated stand-ins.

## What's inside

- `index.html` — the whole page (RTL Persian, one file)
- `assets/` — hero film (desktop + mobile cuts), images, and the vendored libraries (GSAP, ScrollTrigger, Lenis)

## Run it

Open `index.html` through any static server, for example:

```
python3 -m http.server 8000
```

then visit http://localhost:8000. It also works on GitHub Pages (Settings → Pages → deploy from the `main` branch).
